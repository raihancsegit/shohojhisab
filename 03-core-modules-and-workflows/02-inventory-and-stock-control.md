# Inventory & Stock Control

## 1. The Universal Inventory Formula

$$\text{Current Stock} = \text{Opening Stock} + \text{Purchases} + \text{Stock In} - \text{Sales} - \text{Damage/Waste} + \text{Customer Returns}$$

---

## 2. Core Inventory Features
* **Low Stock Alerts:** Highlights items in amber/red when balance falls below threshold.
* **Dead Stock Detector:** Shows products that haven't sold in the last 45 days, helping shopkeepers run discount clearances.
* **Stock Adjustment (স্টক মেলানো):** Weekly physical audit screen to reconcile actual shelf count vs digital count with automated shrinkage/damage logs.
