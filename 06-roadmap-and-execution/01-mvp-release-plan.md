# 12-Week MVP Development Sprint Plan (Full-Stack TypeScript)

| Week | Sprint Target | Deliverables |
|---|---|---|
| **Week 1–2** | **Monorepo Setup & Foundation** | Turborepo setup, shared TypeScript types (`@local-os/types`), Drizzle ORM schema, Fastify/NestJS API, JWT Auth. |
| **Week 3–4** | **Offline Database & Sync Engine** | React Native Expo app, SQLite local storage, Background Sync Queue with reconciliation. |
| **Week 5–6** | **Core Fast POS & Barcode Engine** | Camera barcode scanner, quick sales cart, cash/due ledger, Bluetooth thermal print. |
| **Week 7–8** | **Category Engines (Grocery + Pharmacy)** | Pre-seeded grocery catalog, pharmacy generic search & expiry alerts. |
| **Week 9–10** | **Customer Khata & Reports Dashboard** | Customer due SMS, supplier ledger, daily profit/loss report, bKash subscription gateway. |
| **Week 11–12** | **Field Pilot (10 Real Shops)** | Ground testing in 1 bazaar, bug squashing, UX speed optimization, v1.0 Launch! |
